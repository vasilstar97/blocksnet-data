## Quickstart

Just clone it for an easy start and then:

1. Make virtual environment:

   ```
   $ python3 -m venv .venv
2. Activate it:
   ```
   $ source .venv/bin/activate
3. Install your dependencies:

   ```
   $ pip install -r requirements.txt
4. Choose your venv in jupyter notebook kernel.
